## [0.1.0] - 2026-10-29 @ 06:01

This release is named for the element **Rhenium (Re)**. Rhenium helps jet-engine 
superalloys survive extreme temperatures.

### Summary

Establish the GitHub profile as a minimal BMForge application whose installed
version can be inventoried by CMDB on a workstation. Showcase the open source
projects with locally stored logos so the profile renders independently of
the website repository.

### Added

- Four pinned BMForge baseline skills, project instructions, and standard release tooling.
- Literal `NadimGhaznavi` identity and version metadata for `/opt/prod/nadimghaznavi`.
- Install, upgrade, and uninstall support for the README and constants file, with
  payload verification, file ownership, and a last-successful version marker.
- Disposable-directory lifecycle tests and maintenance instructions covering CMDB
  discovery, installation, upgrades, removal, and the BMForge release workflow.
- Copy the 14-project Open Source Projects section into the README with its
  website, repository, and package links, plus all 14 logos stored in `images/`.
- Include the project logos in installation ownership, verification, upgrades,
  and removal, with coverage for upgrading an existing README-only installation.
